# Carving Depth
ArcGIS tools to estimate the depth of carved features (such as rock art motifs) using raster digital elevation models (DEMs) and polygon annotations for areas of interest or reference points. This repository contains tools developed as part of the Tracing carvers on the rocks project (https://www.gu.se/en/research/tracing-carvers-on-the-rocks).  The tool outputs can be used in deep learning workflows, interpretation, and dissemination. The tools require the ArcGIS Pro software.


## Summary

* <b>CarvingDepth.zip</b>: ArcGIS Pro (v3.7) toolbox to estimate depth at given reference points or within reference polygons at a given interval

* <i>More coming soon...</i>

## Installation
### Carving Depth
Unzip the `CarvingDepth.zip` folder and add the toolbox to your ArcGIS project.
