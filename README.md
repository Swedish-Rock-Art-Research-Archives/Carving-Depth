<h1>Carving Depth</h1>
ArcGIS tools to estimate the depth of carved features (such as rock art motifs) using raster digital elevation models (DEMs) and polygon annotations for areas of interest or reference points. This repository contains tools developed as part of the [Tracing Carvers on the Rocks project](https://www.gu.se/en/research/tracing-carvers-on-the-rocks).   tool outputs can be used in deep learning workflows, interpretation, and dissemination. The tools require the ArcGIS Pro software.


<h2>Summary</h2>

* <b>CarvingDepth.zip</b>: ArcGIS Pro (v3.7) toolbox to estimate depth at given reference points or within reference polygons at a given interval
